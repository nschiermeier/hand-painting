# Webcam Hand Painting

Draw in the air with your fingertips! Try blending colors to create new / unique ones.
Note: Requires a webcam to use.

## Prerequisites

Before you begin, ensure you have met the following requirements:
- You have installed the latest version of [anaconda](https://www.anaconda.com/download)
- You have a Windows/Linux/Mac machine
- You have a webcam, either installed to your computer (like a laptop) or plugged in via USB if external

## Installation

On Windows, Mac, or Linux with anaconda installed:
```sh
PS> conda env create -f environment.yaml
PS> conda activate hand_painting_webcam
```

## Execution / Usage

To run the Webcam Hand Painting, enter into a terminal window:
```sh
$ python main.py
```

## Features

Webcam Hand Painting currently has features for:

- Drawing over your webcam, using it as a canvas
- Changing the color of your brush
- Changing the size of your brush
- Eraser mode, to delete what is drawn on the canvas

### Utilization of Features

There are two actions that are recognized by Webcam Hand Painting:

- To draw / erase on the canvas, hold up and move your index finger
- To select other colors, sizes, or the eraser, hold up your index and middle finger together in the space you're selecting
